💾 Backup & Restore

Download Backup
Backup includes all settings and SMTP configuration. Does not include threat logs.

⚠️ Factory Reset

Resets all settings to factory defaults, clears the dashboard password, and reboots the appliance. Threat logs are preserved. You will be redirected to the setup wizard on reboot.

Option 1 — Reset while logged in

Use this if you are already logged in and want to reset to factory defaults. You will be asked to confirm your current password before the reset runs.

🔑 Option 2 — Locked out or forgotten password

If you can't log in, you can trigger a factory reset using a USB drive — no password required. Click the button below to download honeytrap-reset.txt, then follow the steps below. Your browser will save the file to your Downloads folder — you will need to move it to the root of a USB drive manually.

How to use
  1. Copy honeytrap-reset.txt to the root of a USB drive — not inside any folder
  2. Power off your HoneytrapAI device
  3. Insert the USB drive into any USB port
  4. Power on — the reset will run automatically on boot
  5. Remove the USB drive when the setup wizard appears
